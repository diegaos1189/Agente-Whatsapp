Mapa del Agente

Como funciona este programa de agente

Este agente recibe una instruccion tuya, revisa el contexto disponible, decide si debe leer archivos, usar herramientas, buscar informacion externa o crear documentos, y luego te entrega un resultado verificando lo que hizo.

Flujo principal

1. Tu envias una tarea

Puede ser una pregunta, una peticion de codigo, un diagrama, una automatizacion o una conexion con otra herramienta.

2. El agente clasifica la tarea

Decide si necesita explicar, modificar archivos, buscar datos actuales o usar una integracion externa.

Explicar

Lee el contexto y responde con una sintesis clara.

Editar o crear

Inspecciona el proyecto y hace cambios reales en archivos.

Buscar o conectar

Comprueba herramientas disponibles y consulta fuentes o servicios.

3. Recoleccion de contexto

Lee archivos locales, estructura del proyecto e instrucciones del entorno antes de actuar.

4. Uso de herramientas

Puede usar web, archivos locales, GitHub, Notion, Adobe o generacion de imagenes, si estan disponibles.

5. Ejecucion

Realiza el trabajo: editar codigo, crear HTML, redactar documentos, resumir resultados o preparar una integracion.

6. Verificacion

Comprueba el resultado cuando puede hacerlo, para reducir errores antes de entregartelo.

7. Entrega final

Te explica que hizo, donde quedaron los archivos y cualquier limite real del entorno.

Lo importante

Logica base No improvisa a ciegas

Primero intenta entender el pedido y el entorno antes de tocar archivos o afirmar algo.

Conexiones Solo usa integraciones reales

Si una app no esta disponible aqui, no puede conectarse directo. En ese caso propone una alternativa.

Salida Puede crear documentos

HTML, Markdown, SVG, PDF, imagenes, codigo y documentacion tecnica.
